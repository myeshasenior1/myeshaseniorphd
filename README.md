# Academic Portfolio Website

A responsive single-page academic portfolio inspired by the information architecture of modern HCI researcher websites, while using an original visual design.

## Run locally

Open `index.html` directly in your browser, or from this folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize first

1. Replace every instance of `Your Name` and `you@example.com`.
2. Add your profile photo by replacing `.portrait-placeholder` in `index.html` with an `<img>`.
3. Put your CV at `assets/cv.pdf`, or update that link.
4. Replace placeholder Scholar / LinkedIn / ORCID links.
5. Update publication titles/statuses and news items.
6. Add project detail pages and connect the `View project` links.

## Deploy free

Works as-is on GitHub Pages, Netlify, Cloudflare Pages, or Vercel because it is plain HTML/CSS/JS.
